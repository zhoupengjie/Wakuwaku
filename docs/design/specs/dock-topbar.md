# 顶栏 + dock 规格（定稿，2026-11-02）

用户选定：**顶栏默认 32 px，dock 默认自动隐藏**；第一版里顶栏厚度、dock 占位方式、快速设置和时钟放哪三样都能在「外观」里改。样子见样例 [`docs/prototypes/dock-topbar.html`](../../prototypes/dock-topbar.html)（手画的，不是她的真代码；地址后面带 `#bar=slim&room=auto` 这类记号直接打开某一种）。

2026-11-02 用户改定（在真机上试过第一版之后）：**「顶栏 + dock」是「显示方式」里和灵动岛、任务栏并列的第三种**，不再是任务栏位置的一项（§0、§1）；dock 挂 Windows 的亚克力，模糊它后面真实的窗口，藏起来时整个窗口滑下去、只露出顶上 3 像素（§4、§5）；叫出来更快；dock 里有最小化的窗口和回收站（§4）；启动时一次出现（§8）。灵动岛的卡片上写「该模式计划删去」。

## 0. 已定的

- 是**一种显示方式**，和灵动岛、任务栏并列（设置 `display: "split"`）：和任务栏一样接管 Windows 的任务栏（藏起来、收托盘、拿 Win 键），只是把她那一条拆成两块：屏幕顶上的**顶栏**，底部正中的 **dock**。任务栏选的位置（下、上、左、右）不受它影响。
- 顶栏放她、插件、监控、托盘、输入法、快速设置、时钟；dock 放开始和程序按钮。
- 默认：顶栏 32 px，她在顶栏正中，dock 是居中的一块玻璃、标准图标、碰到窗口就自动隐藏，快速设置和时钟在顶栏。
- 能改的（第一版）：顶栏 32 / 48 px；dock 自动隐藏 / 占着位置；快速设置和时钟在顶栏 / 在 dock。
- 和 MyDockFinder 这类自己管任务栏的工具一起用，照旧用灵动岛（zhoupengjie/Wakuwaku#69）；这个位置一样会和它们抢 Windows 的任务栏，抢的时候照旧让开、换成灵动岛。

## 1. 设置

「外观 → 显示方式」：灵动岛、任务栏之后第三张卡片「顶栏 + dock」（灵动岛那张写着「该模式计划删去」）。选它时下面这一组是：说明一行，然后三行：

| 行 | 选项 | 默认 | 说明 |
|---|---|---|---|
| 顶栏高度 | 32 px · 48 px | 32 px | 48 px 和现在的任务栏一样高 |
| 窗口碰到 dock 时 | 自动隐藏 · 占着位置 | 自动隐藏 | 自动隐藏：窗口能铺到屏幕底边，指针停在底边叫它出来。占着位置：最大化的窗口停在它上面 |
| 快速设置和时钟 | 在顶栏 · 在 dock | 在顶栏 | 点开的是 Windows 自己的面板，只从屏幕底部弹出 |

- 英文：显示方式 "Top bar + dock"（灵动岛下面 "To be removed"）；"Top bar height"；"When a window touches the dock" — "Hide it" / "Keep its room"；"Quick settings and clock" — "In the top bar" / "In the dock"。
- 「任务栏按钮」（图标 / 图标加标题）这一行灰着：dock 只有图标。材质、显示在、布局、她那段的样子照任务栏的。
- 设置的键：`display: "split"`，`splitBar: 32 | 48`，`splitDock: "hide" | "room"`，`splitKeys: "top" | "dock"`。第一版存成 `taskbarEdge: "split"` 的，读进来时换成 `display: "split"`、任务栏位置回到底边。
- 她的右键菜单和托盘菜单里「她的家」也多一项「顶栏 + dock」。
- 「编辑任务栏布局」在这个位置下编辑的是顶栏的三段（§2）；dock 不用编辑，程序按钮照旧拖动排序。

## 2. 顶栏

- 自己登记的 AppBar（上边），和现在任务栏放在顶上一样；材质跟「任务栏材质」走（云母、纯色、透明），细线在下沿。
- **默认布局**：左段放到任务栏上的插件；中段她；右段监控、托盘、输入法、快速设置、时钟。开始和程序按钮不是顶栏的部件（在 dock 里），部件库里也没有它们。她和别的部件照旧能拖到别的段。
- 从顶栏打开的东西都往下长（现在顶边任务栏的样子）：她展开、确认面板、设置（顶栏下面 8 px）、托盘的折叠区（^ 朝下）、插件的卡片。

**48 px**：就是现在顶边的任务栏，部件、胶囊、时钟两行，一样不改。

**32 px**（默认）：每样东西按 32 重新排。

| | 32 px | 48 px（现在） |
|---|---|---|
| 按钮 | 高 28，圆角 5，左右内边距 8 | 高 40，圆角 6，内边距 10 |
| 她的胶囊 | 高 26，离顶 3，圆角 13；头像 20；字 12 | 高 38，离顶 5，圆角 19；头像 24；字 13 |
| 时钟 | 一行：`11月2日 周一 14:42` | 两行：时间、日期 |
| 监控 | 一行：CPU、内存、网速排开 | 两行 |
| 插件 | 只有小档：图标加数值 | 小、中两档 |
| 托盘、输入法、快速设置 | 图标 16，按钮高 28 | 照旧 |

- 胶囊的宽度照「胶囊宽度」（窄 240、标准 300、宽 380），和现在一样。
- 流光：26 高的胶囊，光环外框每边大 3 px（[flowlight.md](flowlight.md) §2），是 32 高，正好是顶栏的厚度。
- 时钟显示秒（Windows 设置里打开了）时一行放得下，不用另做。

## 3. 她

- 在顶栏里和现在顶边的任务栏一样：悬停往下展开成全身加会话列表，要你批准、回答、选择时自己展开成确认面板，设置从她往下长；拉她出来是往下拉，回家落在她头像下面。
- 默认在正中，展开左右对称地往下长（像灵动岛长进了顶栏）。
- 为问题升到全屏上面时只露出她和面板（现在的 `over_full`），顶栏的其余部分不出来。

## 4. dock

**里面放什么**：开始（Windows 打开了「任务视图」时连同它，和现在一样是一个部件）、程序按钮（固定的和开着的，同一个程序合成一个，和现在一样）；一条分隔线后面是**最小化的窗口**（像 macOS：每个窗口一个小格，Windows 把它的实时缩略图画在格子里，右下角是程序的图标，指上去是窗口标题，点一下还原到前面；没有最小化的窗口时没有这一段）；再一条分隔线后面是**回收站**（Windows 自己的图标，空的和有东西的两种，几秒看一次；点一下打开回收站）；快速设置和时钟选了「在 dock」时，最后再一条线后面放它们。

**样子**（样式指南的「浮在上面的」那层）：

| | |
|---|---|
| 位置 | 屏幕底部正中，离底边 2 px |
| 大小 | 高 44；宽跟着按钮多少走，从中间往两边长 |
| 外形 | 圆角 8（Windows 11 的 DWM 圆角），左右内边距 6，按钮之间 2 |
| 底 | Windows 的亚克力挂在 dock 窗口上，模糊它后面真实的东西（窗口也是）；上面一层半透明底色：深色 `rgba(32,32,32,.4)`、浅色 `rgba(243,243,243,.5)`；一圈 1 px 细线加一道顶部高光 |
| 纯色材质 | 不透明的同色底 |
| 关了透明效果、Windows 10 | 用那块屏的壁纸画的云母（没有亚克力） |
| 按钮 | 40×40，圆角 6，图标 24；悬停和前台的底色、开着的程序底下的短线、前台的强调色长线都和现在一样 |
| 会话的小点 | 和现在任务栏按钮上的一样，按心情色 |
| 分隔线 | 1×24，条带细线的颜色，左右各 6 |

- 程序多到放不下：dock 最宽到屏幕宽减两边各 8 px，程序那一段自己横着滚动，两头 12 px 渐隐（和侧边任务栏的那一列一样）。
- 按法和现在主屏任务栏上的程序按钮全部一样：单击、中键、Shift / Ctrl 组合、右键菜单、Shift+右键窗口菜单、拖动排序、拖着文件停在按钮上；窗口列表和缩略图在 dock 上方弹出。
- 不做放大效果（样式指南：不为装饰而动）。

## 5. 自动隐藏（默认）

- **Windows 的任务栏**：藏起来并设成自动隐藏（和现在任务栏在顶、左、右时一样），底部不留位置；工作区只扣顶栏那一条。
- **dock 不占位置**：不登记 AppBar，窗口能铺到屏幕底边。
- **什么时候让开**：有窗口碰到 dock（任务栏上有按钮的、没最小化的窗口，外框伸进 dock 的矩形；和灵动岛「有窗口在下面时收起」的判断一样）。整个 dock 窗口往下滑（0.18 秒），只露出它顶上 3 px 当细边（亚克力挂在窗口上，只能整个窗口一起动）。
- **什么时候出来**：
  - 指针停在屏幕底边（2 px 内）150 ms，整条底边都算，期间没按过鼠标键。
  - 拖着文件停在底边也算，好把文件拖到按钮上。
  - Win+T（键盘焦点进 dock）、开始菜单开着时（Windows 自己的自动隐藏任务栏也这样）。
  - 有窗口闪烁求关注：出来，闪完再按规则收。
- **什么时候收回去**：指针离开 dock（宽出 12 px）和它弹出的东西 0.6 秒，而且还有窗口碰着它。指针还在屏幕最底边（或 dock 下面那 2 px）时不收：以前会收起又被叫出来，来回循环。
- 没有窗口碰着时一直显示。
- 有程序全屏时整个藏起来，细边也不留（和条带一样让开）。

## 6. 占着位置（可选）

- 用 Windows 的任务栏藏起来后留下的底部 48 px（和现在底边的做法一样：藏起来但不自动隐藏）；dock 在这条里，离底边 2 px，两边透出壁纸。
- 最大化的窗口停在 dock 上面；点开始，Windows 的开始菜单正好从 dock 上方弹出。
- 工作区上下两边一起管：顶栏是自己的 AppBar，底部是 Windows 留的位置，工作区自愈要同时看两边（现在一次只看一边）。

## 7. 快速设置和时钟

- **在顶栏**（默认）：在右段最后。点开的快速设置、通知和日历是 Windows 自己的面板，Windows 11 只让它们从屏幕底部弹出，所以出现在右下角，不在按钮下面。设置里那一行的说明写清楚。
- **在 dock**：dock 末尾分隔线后面，时钟两行（不管顶栏多厚）；面板和按钮在同一边。
- 输入法和托盘总在顶栏。
- 2026-11-02 用户要的：快速设置、通知和日历这些 Windows 自己的面板，弹出后挪到顶栏下面的右边（能不能挪得动、会不会被 Windows 挪回去，要在真机上试）。别的程序压到顶栏上的弹窗（比如微信的新消息）也挪到顶栏下面。

## 8. 别的

- **Windows 自己的面板**：开始、搜索、快速设置、通知和日历、输入法列表都从屏幕底部弹出，和现在任务栏在别的边时一样。
- **Win 键**：Win+数字按 dock 上的顺序；Win+T 把焦点放进 dock（自动隐藏时让它出来）；Win+B 放到顶栏的托盘；Tab 在两边之间切换。
- **全屏**：顶栏和 dock 都让开。
- **桌面图标**：从顶栏底下让开（现在顶边已经这样做）。
- **dock 的动画**：最小化的窗口进来时小格长出来、还原时缩回去，dock 的宽度跟着变（2026-11-02 用户要的）。
- **启动时一次出现**：顶栏没有截图可碎，星尘等部件到齐（连续 250 ms 没有新的，最多 1 秒）再一次聚过来；之后才到的部件（托盘图标等）只是淡入，不再各来一股星尘。dock 等它的程序按钮到了才出现（最多等 1.5 秒），从屏幕底下一次滑上来。拆成两股的星尘（中间的按钮留在底部，两头飞上顶栏）以后再做。
- **多显示器**：第一版只管她那块屏；「显示在：所有屏幕」时，别的屏照旧是现在副屏的那种条带，沿底边。

## 9. 不在第一版

- 整条的 dock（就是现在的底部任务栏，只剩开始和程序）。
- 大图标的 dock（64 px：比 Windows 留的 48 px 厚，要自己登记 AppBar，窗口图标也要取更大的）。
- dock 放在左边、右边。
- 别的屏上的顶栏 + dock。

## 10. 还没定的

- 「显示桌面」那条细缝放不放、放哪。样例里没有；Win+D、四指下滑照旧能用。
- 自动隐藏时，Windows 的任务栏设成自动隐藏，开始菜单落在哪里、会不会压住出来的 dock，要在测试虚拟机里看。
- 第一版之后，别的屏要不要也是顶栏 + dock。

## 11. 实现顺序（第一版之内）

每一步在测试虚拟机里试 125%、150%、175%。

1. **位置**：`taskbarEdge` 加 `split`；主窗口按顶边摆（`island.rs`、`appbar.rs` 的顶边照旧），页面 `body` 上多一个类。
2. **48 px 顶栏**：顶边的任务栏去掉 `start`、`apps` 两个部件（`island.js` 的 `TB_PARTS`、`PART_NODES`、预设按位置给不同的一份；`Widgets.layoutOf` 不再把它们补回来）。
3. **dock 窗口**：照 `bars.rs` 开一个窗口，页面用 `bar.html`、`bar.js` 加 dock 的样子；按钮是主屏的（`bars::for_main`）。`bar.js` 补上现在只有主屏才有的：拖动排序、会话小点、拖文件停留。
4. **自动隐藏**：Windows 的任务栏按侧边那样设自动隐藏（`shell.rs` 的 `keep_room`）；dock 不登记 AppBar；让开和叫出来照灵动岛（`island.rs` 的 `look_under`、`tasks::reaches_into`、`call_look`），加上拖文件、Win+T、开始菜单、闪烁求关注。
5. **32 px 顶栏**：`TASKBAR_H` 不再是一个常量（JS、CSS、`island.rs` 的窗口大小和条带厚度），按 §2 的表画部件；流光按 26 高的胶囊。
6. **占着位置**：dock 铺在 Windows 留的底部那条（`explorer_room`）；工作区上下两边一起管（`work_lost`、`set_work_side`、`strip_moved`）。这一步风险最大。
7. **快速设置和时钟进 dock**。
8. **Win 键**：`winkeys.rs` 的顺序取 dock 的；Win+T 进 dock，Win+B 进顶栏。
9. 开发说明（`docs/DEVELOPMENT.md` 的「她的家」）和使用说明（`docs/GUIDE.md` 的「她的家，两种」）各补一段。
